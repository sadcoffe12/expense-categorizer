================================================================
DATABASE SCHEMA (8 Tables)
================================================================

categories
  - id (INT, PK)
  - name (VARCHAR, UNIQUE)
  - type (VARCHAR: Fixed/Variable/Ingreso)
  - color_hex (VARCHAR)
  - icon (VARCHAR)
  - created_at (DATETIME)

expenses
  - id (INT, PK)
  - date (DATE)
  - description (TEXT)
  - description_cleaned (TEXT)
  - amount (FLOAT)
  - category_id (INT, FK)
  - type (VARCHAR)
  - location (VARCHAR)
  - notes (TEXT)
  - source (VARCHAR: manual/import/api)
  - created_at (DATETIME)

rules
  - id (INT, PK)
  - keyword (VARCHAR)
  - category_id (INT, FK)
  - confidence (FLOAT)
  - active (BOOLEAN)
  - created_at (DATETIME)

budgets
  - id (INT, PK)
  - category_id (INT, FK)
  - amount (FLOAT)
  - period (VARCHAR: month/year)
  - start_date (DATE)
  - end_date (DATE)
  - created_at (DATETIME)

alerts
  - id (INT, PK)
  - expense_id (INT, FK)
  - alert_type (VARCHAR: budget_exceeded/anomaly)
  - message (VARCHAR)
  - acknowledged (BOOLEAN)
  - created_at (DATETIME)

categorization_history
  - id (INT, PK)
  - expense_id (INT, FK)
  - original_text (VARCHAR)
  - cleaned_text (VARCHAR)
  - suggested_category_id (INT)
  - user_action (VARCHAR: confirmed/rejected/skipped)
  - created_at (DATETIME)

expense_tags
  - id (INT, PK)
  - expense_id (INT, FK)
  - tag_name (VARCHAR)
  - created_at (DATETIME)

dashboard_config
  - id (INT, PK)
  - config_name (VARCHAR)
  - filters (JSON)
  - layout_preferences (JSON)
  - created_at (DATETIME)

================================================================
API ENDPOINTS (Implemented)
================================================================

Setup (Setup wizard flow)
  POST   /api/setup/validate-sql         - Validate SQL file
  POST   /api/setup/parse-file           - Parse CSV/XLSX headers & preview
  POST   /api/setup/create-database      - Create DB from CSV/XLSX + mapping
  GET    /api/setup/load-database        - Load existing database config

Config
  GET    /api/config/status              - Get configuration status
  GET    /health                          - Health check
  GET    /                                - API metadata

QUICK START
================================================================

1. Terminal 1 - Backend:
   cd /home/aeon95/Downloads/Expense\ Categorizer/expense-categorizer/backend
   python run.py
   → Backend runs on http://localhost:8000

2. Terminal 2 - Frontend:
   cd /home/aeon95/Downloads/Expense\ Categorizer/expense-categorizer/frontend
   npm install      # Only first time
   npm run dev
   → Frontend runs on http://localhost:5173

3. Open browser: http://localhost:5173
   → Setup wizard appears, import data

Alternative: One command
   ./start.sh        # Starts both backend and frontend
